# 플랜두씨 다이어리 (과제 6)

계획(Plan) → 실제로 한 일(Do) → 돌아보기(See)가 하나로 이어지는 다이어리 앱.
로그인 없이 서버의 실제 MySQL 데이터베이스에 저장합니다.

## 준비물
MySQL 인스턴스가 하나 필요합니다. Render는 관리형 MySQL을 제공하지 않으므로,
**Aiven for MySQL**(카드 등록 없이 영구 무료)에서 만든 뒤 접속 정보(Service URI)를 받아옵니다.

## 실행 방법
```
npm install
cp .env.example .env   # 접속 정보 채우기 (Aiven Service URI를 MYSQL_URL에)
npm start
```
`http://localhost:3000` 에서 확인. 서버 시작 시 필요한 테이블을 자동으로 만듭니다(수동 마이그레이션 불필요).

로컬에 SSL 없는 MySQL/MariaDB를 직접 띄워 테스트할 때는 `.env`에서 `DB_SSL=false`로 바꾸세요.
Aiven처럼 SSL이 필요한 원격 DB에 붙을 때는 `DB_SSL=true`(기본값)로 둡니다.

## 배포
- 앱 서버: Render Web Service (Node) — 지금까지처럼 GitHub 연동 배포, 카드 등록 없이 영구 무료
- DB: Aiven for MySQL — 발급받은 Service URI를 Render의 환경변수 `MYSQL_URL`에 등록
- Aiven 무료 서비스는 오래 활동이 없으면 자동으로 꺼집니다. 제출 전에 한 번 접속해서 깨워두고, 꺼져 있으면 Aiven 콘솔에서 다시 켜면 됩니다.

## 짧은 확인 방법
1. 어디로 가나요 — 배포된 주소를 새 시크릿창에서 엽니다.
2. 무엇을 하나요 — "계획" 탭에서 계획을 하나 만들고, "할 일" 탭에서 할 일을 추가한 뒤 완료 처리하고, "돌아보기" 탭에서 기간을 넣고 불러옵니다.
3. 무엇이 보이면 통과인가요 — 돌아보기 화면의 숫자(완료/지연/막힘 등)를 누르면 그 숫자가 나온 할 일 목록이 아래에 뜹니다. 새로고침해도, 서버를 재시작해도 계획·할 일·기록이 그대로 남아 있습니다.
4. 안 될 때 — 숫자를 눌러도 목록이 안 뜨면 기간(시작일/종료일)이 계획의 기간과 겹치는지 확인하세요.
